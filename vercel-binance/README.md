# Conector regional de Binance

Función alojada en la región de São Paulo (`gru1`) para comprobar y consultar Binance USDⓈ-M Futures cuando el proveedor principal recibe bloqueos regionales.

Las claves privadas deben registrarse como variables cifradas de Vercel y nunca guardarse en este directorio:

- `BINANCE_API_KEY`
- `BINANCE_SECRET_KEY`
- `RELAY_TOKEN`
